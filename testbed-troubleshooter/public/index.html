Testbed Troubleshooter

Finds out whether the hub–spoke testbed is broken at layer 2 (portgroup / VLAN / MAC) or layer 3 (routing), and says exactly where. Read-only: it reads ESXi and the guests and sends ARP/ICMP probes — it changes nothing.

ESXi host

The host that runs the testbed VMs. SSH must be enabled (Host → Actions → Services → Enable Secure Shell). Used to read vSwitches, portgroups, VLAN IDs and vNIC MACs — that is what makes an L2 verdict possible.
